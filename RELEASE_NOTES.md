A Windows desktop front-end for [Microsoft MarkItDown](https://github.com/microsoft/markitdown) (0.1.9).

**Download `MarkItDownGUI.exe` below.** It's a single file with nothing to install. The first launch takes a few seconds while it unpacks.

- Batch-convert PDF, Word, PowerPoint, Excel, Outlook .msg, HTML, CSV, EPUB and more to Markdown
- Add files, whole folders, drag & drop, or URLs (including YouTube transcripts)
- Live Markdown preview with Copy / Save As
- Save `.md` files next to each source or into one output folder

Windows SmartScreen may warn because the exe is unsigned: click **More info → Run anyway**.
